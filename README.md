Introduction

The mini academic website is a web-based application designed to provide students with convenient access to academic information. It contains pages for courses,studies materials,about,and contact informations page.
The purpose of developing an Academic Website is to make the sharing and accessing of academic information easier, faster and more convenient. Students can use the website to access learning materials, check announcements, view their academic information and stay updated on important school activities.
The system was developed using HTML for structure, CSS for presentation or style, and JavaScript for interactivity.

Aim and Objective:

The aim of this project is to design and develop a user-friendly Academic Website that provides students, lecturers and educational institutions with an easy and reliable platform for accessing academic information, educational resources and important school updates.

The specific objectives of the Academic Website are:
To develop a user-friendly and responsive academic website.
To provide students with easy access to academic information and learning materials.
To enable lecturers to share educational resources and important announcements.
To provide updated information about courses, departments and academic programmes.
